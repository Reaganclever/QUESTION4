# QUESTION4
1. HTML:
o A page with a table to display employee details.
o A button labeled "Add Employee" to trigger the prompt for entering new
employee details.

2. CSS:
o Style the table and button to make them visually appealing.
o Center the content on the page for a clean layout.

3. XML:
o Store the employee details (e.g., Employee ID, Name, Age, Department).

4. JavaScript:
o When the "Add Employee" button is clicked:
▪ Prompt the user to enter the employee's ID, Name, Age, and Department.
▪ Validate the inputs (e.g., all fields must be filled).
▪ Update the XML database with the new entry.
▪ Display the updated table with the new employee details.

Expected Output:
1. An empty table at the start with columns for Employee ID, Name, Age, and Department.
2. Clicking "Add Employee" prompts the user to input employee details.
3. Valid inputs add a new row to the table and update the XML database.
4. The XML database structure dynamically grows as new employees are added.
